# CircleForge
This is a circular project for learning/demonstrating a complete ML data pipeline from data generation to model. 
Our end goal is to use a procedurally generated data base as fodder for creating ML generated images. 

To help along the way we'll want to build a few different models:
1) A supervised task that takes images and counts the number of circles / areas (Bonus, check if it can detect hidden algorithmic features)
2) The generator that makes circle images, without knowing the rules
3) A supervised discriminator for checking if our images were procedurally or generatively coded. 
The synthetic database encoded is meant to be a playground for understanding different kinds of modeling architectures and demonstrating the power of physical heuristics for informing models. 


This folder contains a small image generation project that uses generative modeling to "discover" parameters underlying images that are procedurally generated/generate images from the same family.

## Synthetic Data 
The images in the data base look something like this:
![Image generated with gen.CircleDoodle(size=600, max_circle = 20, fill_percent = 0.01, filename="name.npy")](doc/doc_images/sample_image.png)
They're generated by placing large circles randomly, filling the perimeters with smaller circles some size fraction of the large circles, and assuring that no overlap happens between circles. 
The remaining negative space is then speckled randomly with the specified fill density.

### Part 1: Procedurally Generated Doodles (Training Data)
The script generatorlib.py defines a class that generates each drawing along with statistics about the drawing as labels that a model can learn.
Circles are drawn with the CV2 library in python 
## Drawing API
```
# Import library with Doodle class
import generatorlib as gen

# Create a doodle object with user specified algorithm parameters
doodle_obj = gen.CircleDoodle(size=600, max_circle = 1, fill_percent = 0.01)

# Draw image according to parameters
doodle_obj.fill_space() 

# Save image and image labels into a data_base folder
doodle_obj.add_to_data_base("data_folder") # Labels go into annotations.csv inside the passed data folder, while image ndarrays are saved as "default.npy" or filename when that arg is also passed. 
```
## API for loading Doodles from saved Data

```
doodle_obj2 = gen.CircleDoodle()
doodle_obj2.load_circle_obj_from_data("data_folder/annotations.csv","data_folder/name.npy")
```

## API for checking objects/equivalence
